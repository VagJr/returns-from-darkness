This public repository contains the community website, multilingual project documentation, the modified client source/patch and public release links. It does not contain DIABDAT.MPQ, TH3data.mor, account databases, private signing keys or player save files.

Diablo and Battle.net are trademarks of their respective owners. This is an independent, non-commercial fan project, not affiliated with Blizzard Entertainment. The classic Diablo lettering and flame animation are derived from the reference supplied by the project owner; those elements are not claimed as original artwork or relicensed here. Project-specific suffix lettering and website layout are custom work. Concept illustrations are AI-generated art and are identified separately from real client screenshots. Font licenses are preserved in site/dist/assets/fonts.

The current Windows client is adapted from The Hell 3 source 1.265 with matching mod data 1.267, on top of Diablo/Hellfire. The classes, traits, areas, existing items, spells, interface layouts and most game artwork inherited from those projects are not claimed as Returns from Darkness creations. The original source README is retained in client-source and the distribution. Earlier prototypes used DevilutionX; its Sustainable Use License and notices remain applicable to code derived from that engine.

The partial stone-floor material comes from the DamnationX 1.6.0 beta 3 distribution. It is not a port of the complete DamnationX WebGPU renderer. Sanctuary portraits are adapted from the existing mod resource archive. The project does not claim authorship or relicense these assets. Original project work includes the community hub, client/account integration, launcher/update flow and Sanctuary account progression layer; third-party libraries and services retain their respective notices.

Version 0.4.1 adds project-specific HUD framing, an inventory backdrop, native notice composition, an original vector emblem and the three-item First Vigil collection. Original relic icon artwork and the Sanctuary cathedral illustration were generated for this project; sprite conversion and interface geometry are project-specific code. This does not claim authorship of the inherited HUD layout, item system or other equipment. The prompts and asset provenance are preserved in client-source/content/original/ART-DIRECTION.md.

Native room gameplay is hosted by the room creator, with cloud accounts, discovery and relay. The public package imports compatible game data during first preparation. Full replacement HD artwork, automatic host migration and authoritative competitive rankings are not part of the current completed content.

Version 0.4.2 adapts the complete health and mana vessels from Tchernobog 0.2.2f, preserving their statues, framing and liquid: 48 original 256x256 RGBA frames per resource in 2048x1536 atlases, with about 110 pixels of useful liquid diameter per frame. This inherited vessel artwork is not claimed as original Returns from Darkness artwork. The project-specific shader provides circular clipping and independent resource fill composition. Only the two runtime vessel atlases and provenance metadata are included in client-source/content/visual/tchernobog/orbs-runtime; extraction previews and raw audit sources are excluded.
