# Returns from Darkness HD 0.4.7

Community client adapted from The Hell 3 source 1.265/data1.267, with creator-hosted online rooms, signed updates and Sanctuary account progression. Inherited gameplay and artwork remain credited; project-specific additions include the integration, progression layer, interface framing and First Vigil relic collection. See NOTICE.md and ORIGINAL-SOURCE-README.txt.

Apply engine.patch to TH3 1.265, then copy engine-assets/ into that source tree (res/rfd.ico is required by the native resources). Build native/thehell3-online first; engine uses Win32 MSVC v145, Windows SDK10.0.26100.0, /MT and /Z7. RfdDevQa must remain0 in public builds. The source README must remain with redistributions.

Companion dependencies: libdatachannel0.24.6 commit6b1e2e620f1e37f0eafeee702eaea0043cb305fd and MbedTLS3.6.5 commite185d7fd85499c8ce5ca2a54f5cf8fe7dbe3f8df, with recursive submodules. Build peer-bridge Release x64. Its gameplay transport is ordered reliable WebRTC; Cloudflare handles accounts, discovery, profiles and authenticated relay fallback. The room creator runs the simulation. No automatic host migration or authoritative ranked PvP.

Compile Launcher.cs + Lang.cs for .NET Framework4 WinForms with Drawing, Security, Web.Extensions and IO.Compression/FileSystem. Embed assets/{sanctuary.jpg,logo.gif,title.ttf,body.ttf,launcher-locales.json,project.ico} by filename, update-public.xml as update-public.xml, and use project.ico as /win32icon. The setup additionally embeds initial.zip with the signed release.json. Private signing keys are excluded.

Copy content/original/items to game assets/original/items, and content/original/ui to assets/original/ui. The original basalt/iron interface material is decoded once as RGBA and composed with an A8 mask after the world pass, preserving gameplay geometry and native controls. The PNG relic icons are decoded/scaled/palettized once at load; native CEL inventory/ground frames are derived from those originals. Stable unique IDs4618..4620 and reserved private lines avoid adding them to old random unique selection. The three explicit rewards are restricted to Normal campaign/Horror: Skeleton King, Butcher and classic Diablo respectively. Existing global rate tables remain unchanged. See docs/COLECAO-PRIMEIRA-VIGILIA.md for conditions and effects.

Rules sanctuary-1 and all engine mode IDs are preserved (Normal0, Hardcore1, Ironman2, Nightmare3, Easy4, Survival5, Hard6, Speedrun7, Coliseum8). Progress reports are client-reported and unranked. Saves remain local; profiles do not back up complete inventories. The public setup imports compatible game data on first preparation.

0.4.1 fixes D3D9 menu surface operations, repaints dialogs after activation/reset and replaces ordinary account/room/unlock notices with skinned native dialogs. The original interface framing preserves native hitboxes and item/equipment layouts. This is not a whole-world HD artwork replacement or a port of another project's complete renderer. Browser gameplay and full remaster remain in development.

For 0.4.2 and later, copy health-vessel-atlas.png and mana-vessel-atlas.png from content/visual/tchernobog/orbs-runtime into game assets/remaster. CommunityOrb.hlsl is part of engine.patch and is compiled into the embedded shader header; preserve it when rebuilding. The 2048x1536 atlases contain 48 complete 256x256 RGBA frames per resource from Tchernobog 0.2.2f, preserving their statues, framing and liquid. Each original source canvas contains a useful liquid sphere about 110 pixels across; this is not 256-pixel native liquid detail. The project shader supplies circular clipping and independent resource fill. Provenance and per-frame hashes are included, while extraction previews and raw audit sources are excluded. The inherited vessel artwork is credited to Tchernobog, not claimed as original project artwork. See docs/RENDERIZACAO-HUD-0.4.2.md.

Version 0.4.3 uses the project owner's Dark Gothic HUD Kit for the complete panel frames, guardian sculptures, recesses, equipment wells and buttons. The original 52 PNGs remain byte-exact under content/original/hud-kit/source. The runtime 2048x2048 atlas packs 24 pieces with transparent gutters; integration.json records provenance and hashes. Rebuild the atlas and CommunityHudAtlas.h using prepare-gothic-hud-kit.py, then compile CommunityHudKit.hlsl. Live inventory remains 10x7 and the belt keeps eight cells. Fixed sample values, items and potion pictures are excluded from composition. Tchernobog supplies the animated liquid only when the new kit is present; its old vessel/statue rendering remains a fallback. See docs/RENDERIZACAO-HUD-0.4.3.md.

Version 0.4.5 preserves the world underneath transparent HUD edges, composes party chat with the kit, adds restrained slot highlights and gives item descriptions an independent textured background. Native text, equipment rules and gameplay rates remain unchanged. See docs/RENDERIZACAO-HUD-0.4.5.md.

Version 0.4.6 adds the initial English/Portuguese choice, a reviewed menu translation layer and original archive music fallback when optional music packs are missing. Whole-game translation and accented glyph support remain in progress. The Ashes of the Return collection includes 36 original artworks and a masked RGBA inventory atlas; balance, natural acquisition and original equipped animations remain in development. Daily contracts are disabled by default and must not be advertised as publicly available.

Version 0.4.7 fixes guest admission before the creator opens the game, retries authenticated HTTPS relay requests, gates guest launch on host world handshake, clears departed room slots, excludes closed sockets, and recovers a local ended connection without a circular service call. Unicode account control and compatible native executable paths are repaired. Sanitized connection diagnostics are available in the launcher tray menu. No external-PC graphical certification is implied. See docs/AUDITORIA-CONEXOES-0.4.7.md.
