# Diablo 1 HD — Returns from Darkness

Diablo 1 HD — Returns from Darkness는 옛 Battle.net의 만남을 되살리는 독립 비영리 프로젝트입니다. HD 비주얼과 새로운 자체 콘텐츠를 개발하고 있습니다.

**공개 서버에서 벌써 플레이할 수 있나요?**

아직 아닙니다. 0.1.6은 로컬 테스트 버전입니다. Discord에서 개발 상황과 향후 테스트를 확인할 수 있습니다.

**원본 Diablo가 필요한가요?**

네. 플레이어 본인의 설치 파일이 필요합니다. 프로젝트는 DIABDAT.MPQ나 상용 게임 데이터를 배포하지 않습니다.

**모든 HD 그래픽과 아레나가 완성됐나요?**

아직 아닙니다. 현재 클라이언트는 원본 아트를 1280 × 720 프로필로 사용합니다. HD 재작업, 새 지역, 아레나는 제작 목표이며 공개 출시일은 정해지지 않았습니다.

독립적인 무료 비영리 팬 프로젝트이며 Blizzard와 관련이 없습니다. Diablo와 Battle.net은 각 소유자의 상표입니다.

개발, 번역, 콘셉트 일러스트에 AI의 도움을 활용합니다. 사이트의 콘셉트 아트는 실제 게임 플레이 화면이 아닙니다. DevilutionX 기여자와 원작 Diablo 개발자에게 감사를 표합니다.
