## 常见问题

### 如何开始？

下载Windows客户端，登录后创建或选择房间。房间按钮可打开游戏，游戏内大厅也可访问社区。启动器在开始新游戏前检查最新版，并从已有安装中导入兼容的游戏文件。 从网站打开游戏时，同一账号也会登录游戏内大厅。从已登录的游戏或启动器打开社区时，登录状态会转到浏览器。

### 我需要在电脑上运行服务器吗？

账号、聊天和房间列表留在云端。创建者的客户端通过直接连接或受限网络的中继来主持游戏。创建者需要留在游戏中；退出会结束队伍会话。

### 角色会保存吗？

会。游戏中的自动保存和正常退出会把背包、金币和成长保存到本机的独立账号档案，与更新文件分开存放。不支持跨电脑同步，房间世界也不是持久世界。

### 完整重制和竞技场完成了吗？

客户端支持Full HD分辨率和视觉改进，并保留经典精灵图。全部高清美术替换仍只完成了一部分。Coliseum已作为客户端挑战存在；在线PvP竞技场、排名和活动仍在开发和验证中。
