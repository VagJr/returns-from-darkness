# Diablo 1 HD — Returns from Darkness

Diablo 1 HD — Returns from Darkness 是一个独立、非商业的社区项目，旨在重现经典 Battle.net 的玩家聚会体验，同时开发 HD 视觉更新与原创内容。

## 有些地方，始终在呼唤我们。

崔斯特瑞姆的寂静，大教堂的门，与朋友再深入一层的感觉。

我们希望保留 Diablo 1 的氛围，并开辟新道路：社区服务器、焕新的画面以及可以共同探索的冒险。

## 冒险开始前的相聚。

一个集中社区、聊天频道以及每间最多四人的多个房间。聚会体验参考经典 Battle.net，技术整合采用围绕 PvPGN 和 DevilutionX 构建的自有服务。

**当前已实现 — v0.1.6**

本地版本0.1.6已将登录、频道、聊天和房间整合进客户端。0.1.4和0.1.5已确认可通过图形界面进入崔斯特瑞姆；新的原生流程仍在验证中。制作工具支持编辑数据表、导入精灵图和准备内容。

**下一步**

验证两个图形客户端共同游戏、中途加入及房主退出；继续推进HD重制，并在开放服务器前保护和测试外部连接。

网络测试不等于四人的完整图形游戏验证。存档与模拟仍在客户端执行。服务器尚未向公众开放。

## 用心制作，透明开发。

### 崔斯特瑞姆再次载入 · 本地基础已验证

已整合自定义客户端、PvPGN、启动器和本地房间。版本 0.1.4 首次进入游戏世界已获确认。

### 让归来逐渐成形 · 开发中

HD美术和界面正在开发中。客户端已有定制大厅界面，完整的图形重制仍在制作阶段。

### 初光与灰烬竞技场 · 内容原型

引擎表中加入五件物品与两种变体。两张生成的地图等待整合；1v1 和 2v2 对战尚不可玩。

## 常见问题

### 需要原版 Diablo 吗？

需要。玩家必须使用自己安装的游戏文件。项目不分发 DIABDAT.MPQ 或商业游戏数据。

### 现在能在公开服务器游玩吗？

暂时还不能。0.1.6是本地测试版本。欢迎加入Discord了解开发进度和后续测试。

### 这是官方重制或 MMO 世界吗？

这是与 Blizzard 无关联的独立粉丝项目。每局最多四人，大厅可汇集多个队伍，但并非所有玩家共享的持久世界。

### 完整 HD 画面与竞技场已完成吗？

尚未完成。目前客户端使用原版美术及 1280 × 720 配置。HD 重制、新区域与竞技场是开发目标，尚未确定公开发布日期。
