# Diablo 1 HD — Returns from Darkness

拡張された冒険へ、トリストラムに帰ろう。29のキャラクター育成ルート、数千の装備ベース、魔法、才能、挑戦が待っています。オンラインハブで最大4人の仲間を集め、Returns from Darkness HDのWindowsクライアントで旅を続けましょう。

## いつまでも呼び続ける場所がある。

トリストラムの静寂。大聖堂の扉。仲間ともう一階深くへ。

多彩な育成、探索、装備とともに名作を再発見。アカウント、チャット、ルームがコミュニティハブに集まり、各グループがReturns from Darknessの世界で自分たちの冒険を楽しめます。

## 冒険の前に、集まる場所を。

アカウント、チャットチャンネル、最大4人のルームを備えたコミュニティハブ。サイトやゲーム内ハブで仲間を見つけましょう。ハブはクラウドにあり、ゲームはプレイヤーがホストします。

**このビルドで利用可能 — v0.3.5**

ハブ内蔵Windowsクライアント、最大4人の協力ルーム、自動更新、アカウント別プロフィール。アイテムシステムはルーム内のドロップを共有し、自動保存で所持品、ゴールド、キャラクターの成長をこのPCに保管します。

**次の章**

統一感のある素材と画像でリマスターを拡張し、制作ツールを改善。外部ネットワークでのゲーム、オンラインColiseum、PvPアリーナ、イベントを検証します。

ハブはクラウドサービスを利用し、ゲームは各クライアントで実行されるため、ルーム作成者は接続を維持する必要があります。キャラクターはこのPCに自動保存され、復元用コピーも作成されます。新しいルームは新しい世界を生成します。全画像のHD化、ホスト移行、PvPランキングは未完成です。

## よくある質問

### どう始めればいいですか？

Windowsクライアントをダウンロードし、ログインしてルームを作成または選択します。ルームのボタンでゲームが開き、ゲーム内ハブからもコミュニティにアクセスできます。ランチャーは新しいゲームの前に最新版を確認し、インストール済みの互換ゲームファイルを取り込みます。 サイトからゲームを開くと、ゲーム内ハブにも同じアカウントでログインします。ログイン済みのゲームやランチャーからコミュニティを開くと、ブラウザーにもログインが引き継がれます。

### 自分のPCでサーバーが必要ですか？

アカウント、チャット、ルーム一覧はクラウドにあります。ルーム作成者のクライアントがゲームをホストし、直接接続または制限のあるネットワーク向けの中継を使います。作成者がゲームを退出すると、グループのセッションが終了します。

### キャラクターは保存されますか？

はい。プレイ中の自動保存と通常終了で、所持品、ゴールド、成長をこのPCのアカウント別プロフィールに保存します。更新とは別に保管されます。PC間の同期はなく、ルームの世界は永続ではありません。

### リマスターとアリーナは完成していますか？

Full HD解像度と見た目の改善を利用でき、従来のスプライトも保持しています。全画像の高精細化はまだ一部です。Coliseumはクライアント内の挑戦として存在し、オンラインPvPアリーナ、ランキング、イベントは検証・開発中です。
