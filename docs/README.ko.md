# Diablo 1 HD — Returns from Darkness

Diablo 1 HD — Returns from Darkness는 옛 Battle.net의 만남을 되살리는 독립 비영리 프로젝트입니다. HD 비주얼과 새로운 자체 콘텐츠를 개발하고 있습니다.

## 어떤 장소는 언제나 우리를 부릅니다.

트리스트럼의 고요함. 대성당의 문. 친구와 한 층 더 내려가던 그 느낌.

Diablo 1의 분위기를 지키며 새로운 길을 열고자 합니다. 커뮤니티 서버, 새로워진 그래픽, 함께 나눌 모험을 준비합니다.

## 모험 전에 만나는 곳.

하나의 커뮤니티, 채팅 채널, 각 최대 4명인 여러 방. 옛 Battle.net에서 영감을 얻고 PvPGN과 DevilutionX를 중심으로 자체 서비스를 통합합니다.

**현재 작동하는 기능 — v0.1.6**

로컬 버전 0.1.6은 로그인, 채널, 채팅, 방을 클라이언트에 통합합니다. 0.1.4와 0.1.5에서 그래픽 화면으로 트리스트럼에 진입한 것을 확인했으며 새 네이티브 흐름은 검증 중입니다. 제작 도구는 테이블 편집, 스프라이트 가져오기, 콘텐츠 준비를 지원합니다.

**다음 단계**

그래픽 클라이언트 두 대로 플레이, 늦은 참가, 방장 퇴장을 검증하고 HD 개편을 확장합니다. 서버 공개 전에 외부 연결을 보호하고 테스트합니다.

네트워크 테스트는 4명의 완전한 그래픽 플레이 검증이 아닙니다. 저장과 시뮬레이션은 아직 클라이언트에 있습니다. 서버는 일반에 공개되지 않았습니다.

## 정성껏 만들고, 투명하게 개발합니다.

### 트리스트럼이 다시 로딩됩니다 · 로컬 기반 검증 완료

커스텀 클라이언트, PvPGN, 런처, 로컬 방을 통합했습니다. 0.1.4에서 첫 월드 진입을 확인했습니다.

### 귀환에 형태를 부여하기 · 개발 중

HD 아트와 인터페이스를 개발 중입니다. 클라이언트에는 전용 로비 인터페이스가 있으며 전체 그래픽 개편은 아직 제작 중입니다.

### 첫 번째 빛과 잿빛 아레나 · 콘텐츠 프로토타입

엔진 테이블에 아이템 5개와 변형 2종이 있습니다. 생성된 지도 2개는 통합 대기 중이며 1v1과 2v2는 아직 플레이할 수 없습니다.

## 자주 묻는 질문

### 원본 Diablo가 필요한가요?

네. 플레이어 본인의 설치 파일이 필요합니다. 프로젝트는 DIABDAT.MPQ나 상용 게임 데이터를 배포하지 않습니다.

### 공개 서버에서 벌써 플레이할 수 있나요?

아직 아닙니다. 0.1.6은 로컬 테스트 버전입니다. Discord에서 개발 상황과 향후 테스트를 확인할 수 있습니다.

### 공식 리메이크 또는 MMO인가요?

Blizzard와 관련 없는 독립 팬 프로젝트입니다. 게임당 최대 4명이며 로비가 여러 그룹을 모을 수 있지만 모두가 공유하는 영구 월드는 아닙니다.

### 모든 HD 그래픽과 아레나가 완성됐나요?

아직 아닙니다. 현재 클라이언트는 원본 아트를 1280 × 720 프로필로 사용합니다. HD 재작업, 새 지역, 아레나는 제작 목표이며 공개 출시일은 정해지지 않았습니다.
