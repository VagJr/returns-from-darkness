# Diablo 1 HD — Returns from Darkness

확장된 모험을 위해 트리스트럼으로 돌아오세요. 29가지 캐릭터 성장 경로, 수천 가지 장비 기반, 마법, 특성, 도전이 기다립니다. 온라인 허브에서 최대 4명의 동료를 모아 Returns from Darkness HD Windows 클라이언트에서 여정을 이어가세요.

## 어떤 장소는 언제나 우리를 부릅니다.

트리스트럼의 고요함. 대성당의 문. 친구와 함께 한 층 더 깊이 내려가는 순간.

더 다양한 성장, 탐험, 장비로 고전을 다시 만나세요. 계정, 채팅, 방은 커뮤니티 허브에서 연결되며 각 그룹은 Returns from Darkness에서 자신만의 모험을 즐깁니다.

## 모험 전에 만나는 곳.

계정, 채팅 채널, 최대 4인 방을 제공하는 커뮤니티 허브입니다. 사이트나 클라이언트에서 동료를 찾으세요. 허브는 클라우드에 있고 게임은 플레이어가 호스팅합니다.

**이번 빌드에서 이용 가능 — v0.3.5**

허브가 통합된 Windows 클라이언트, 최대 4인 협동 방, 자동 업데이트, 계정별 프로필. 아이템 시스템은 방의 드롭을 공유하고 자동 저장으로 인벤토리, 금, 캐릭터 성장을 이 PC에 보관합니다.

**다음 장**

일관된 소재와 이미지로 리마스터를 확장하고 제작 도구를 개선합니다. 외부 네트워크 플레이, 온라인 Coliseum, PvP 아레나, 이벤트를 검증합니다.

허브는 클라우드 서비스를 사용하며 게임은 각 클라이언트에서 실행되므로 방 생성자는 연결을 유지해야 합니다. 캐릭터는 이 PC에 자동 저장되며 복구 사본을 만듭니다. 새 방은 새 세계를 생성합니다. 전체 HD 이미지, 호스트 이전, PvP 랭킹은 아직 완성되지 않았습니다.

## 정성껏 만들고, 투명하게 개발합니다.

### 커뮤니티가 온라인에 있습니다 · 이용 가능

계정, 채널, 채팅, 방을 사이트에서 이용할 수 있으며 관리자 PC가 켜져 있을 필요가 없습니다.

### 확장된 여정 · 클라이언트 내

29가지 성장 경로, 장비, 재능, 마법, 도전이 현재 클라이언트에 포함됩니다.

### 귀환은 계속됩니다 · 개발 중

Full HD, 소재 개선, 움직이는 로고가 시각적 방향을 만듭니다. 전체 이미지 리마스터와 잿빛 아레나는 제작 중입니다.

## 자주 묻는 질문

### 어떻게 시작하나요?

Windows 클라이언트를 다운로드하고 로그인한 뒤 방을 만들거나 선택하세요. 방 버튼으로 게임을 열고 게임 내부 허브에서도 커뮤니티에 접근할 수 있습니다. 런처는 새 게임 전에 최신 버전을 확인하고 설치된 게임의 호환 파일을 가져옵니다. 사이트에서 게임을 열면 게임 내 허브에도 같은 계정으로 로그인됩니다. 로그인된 게임이나 런처에서 커뮤니티를 열면 브라우저에도 로그인이 이어집니다.

### PC에서 서버를 실행해야 하나요?

계정, 채팅, 방 목록은 클라우드에 있습니다. 방 생성자의 클라이언트가 직접 연결 또는 제한된 네트워크용 중계로 게임을 호스팅합니다. 생성자가 게임을 나가면 그룹 세션이 종료됩니다.

### 캐릭터가 저장되나요?

네. 플레이 중 자동 저장과 정상 종료로 인벤토리, 금, 성장을 이 PC의 계정별 프로필에 보관하며 업데이트와 분리됩니다. PC 간 동기화는 없고 방 세계는 영구적이지 않습니다.

### 리마스터와 아레나는 완성됐나요?

Full HD 해상도와 시각적 개선을 제공하면서 고전 스프라이트를 유지합니다. 전체 고해상도 이미지 교체는 아직 일부만 적용됐습니다. Coliseum은 클라이언트 도전으로 존재하며 온라인 PvP 아레나, 랭킹, 이벤트는 검증 및 개발 중입니다.
